# TTF Brand Site

Bilingual French and Traditional Chinese website for Taiwan Tech France Association (TTF).

## Pages

- `index.html`: Traditional Chinese version (default)
- `fr.html`: French version
- `zh.html`: Traditional Chinese legacy URL
- `mentions-legales.html`: Legal notice

## Local preview

Serve the repository root with any static file server, then open `index.html`.

The published GitHub Pages site lives at:

`https://ttf-tech.github.io/branding-site/`
